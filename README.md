# Horizon's Bar — Betio, South Tarawa

A one-page website for Horizon's Bar on Betio Island, South Tarawa, Kiribati.

## Files
- `index.html`: page content
- `styles.css`: design and animations
- `main.js`: stars, scroll effects, live Tarawa clock and sunset times

There's no build step. Open `index.html` in a browser, or host the folder on any static host (GitHub Pages, Netlify, etc.).
